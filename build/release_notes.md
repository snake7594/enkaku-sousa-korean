PSP **원격수사 ~真実への23日間~** (`UCJS10088`) 한국어 패치 초판입니다.

## 적용 방법

원본 ISO는 **직접 덤프한 것**을 사용하십시오. 이 릴리즈는 게임 데이터를 포함하지 않습니다.

### 1. 원본 확인

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
크기   739,835,904 바이트
MD5    9f9bb5eec3d2c37f184955b591923e1c
```

MD5가 다르면 패치가 적용되지 않거나 깨진 결과가 나옵니다.

### 2. 패치

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean.xdelta Enkaku_Korean.iso
```

xdeltaUI를 쓰는 경우 **Apply Patch** 탭에서 Patch에 `.xdelta`, Source에 원본 ISO를 지정하십시오.

### 3. 결과 확인

```
크기   739,835,904 바이트 (원본과 동일)
MD5    e1ae1cdb39255e75eb52e82c7fb8f7e3
```

크기가 원본과 같은 것이 정상입니다. 파일을 추가하거나 옮기지 않고 기존 데이터를 제자리에서 교체하기 때문입니다.

PPSSPP와 실기(CFW) 모두에서 동작합니다.

## 알려진 문제

일부 대사에 문장 끝 마침표가 빠지거나 띄어쓰기가 소실된 구간이 있고, 초벌 번역의 어색한 표현이 남아 있습니다. 품질 개선은 계속 진행 중입니다.

## 개발 내역 요약

문자표에 **중복 배정 423슬롯**이 있어 원문 자체가 깨져 있었습니다. 글리프를 이미지로 렌더링해 육안 대조하는 방식으로 **248슬롯을 정정**했고, 그 결과 원문 **1,886행**이 달라졌습니다. 인명 `播磨`(하리마), 지명 `宮上銀座`(미야카미 긴자), 형사 이름 `三浦`(미우라)가 이때 복원됐습니다. `三浦`는 그전까지 `退職`(퇴직)으로 읽히고 있었습니다.

텍스처 인코더는 디코더의 역함수로 구현하고 **449장 전부에 대해 왕복 무손실**을 확인한 뒤 사용했습니다.

아카이브를 다른 LBA로 옮긴 빌드는 실기에서 `C1-2858-3` 오류가 났습니다. 아카이브가 원본과 같은 크기이므로 **원래 위치에 제자리 교체**하도록 되돌렸고, 실행 파일(`EBOOT.BIN`, `BOOT.BIN`, `PARAM.SFO`, `UMD_DATA.BIN`)은 일절 수정하지 않습니다.
