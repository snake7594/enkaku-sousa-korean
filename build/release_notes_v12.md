```

```

```

원본 MD5    9f9bb5eec3d2c37f184955b591923e1c
```

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v1.2.xdelta Enkaku_Korean.iso
```

```
결과 크기   739,835,904 바이트 (원본과 동일)
```

이전 버전에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오. v1.0이나 v1.1 결과물에 덧씌우면 안 됩니다.

## v1.2에서 고친 것

### 설정 화면 정렬

회색 배경 글씨와 노란색 선택 글씨가 어긋나 있던 문제입니다. 원인이 두 가지였고, 둘 다 좌표를 임의로 정한 데서 나왔습니다.

- **오버레이** — 일본어 원본은 128×32 상자 안에서 잉크가 `x=1`부터 시작하는 **왼쪽 정렬**인데, 한국어를 가운데 정렬로 그려서 선택된 줄이 오른쪽으로 밀렸습니다.
- **배경 패널** — 원본 8줄이 `x=36`, `y=75`에서 시작해 간격 22로 놓여 있는데, 한국어를 `x=30`, `y=80`에 다른 간격으로 그렸습니다.

이번에는 원본 텍스처에서 잉크 위치를 직접 측정해 그 자리에 그렸습니다. 오버레이는 각자의 원본 정렬을 따르게 해서, 항목명 40장은 왼쪽 정렬로 맞추고 값(보통·중간 등) 23장은 가운데 정렬을 유지했습니다.

## 여전히 남은 것

| 항목 | 사유 |
|---|---|
| 하단 버튼 (`選択`·`戻る`·`決定`) | 여러 문자열이 한 텍스처에 조각으로 붙어 있고 조각 경계가 실행 코드에 있습니다. 위치를 모른 채 고치면 HUD 전체가 깨집니다 |
| 타이틀 메뉴 (`最初から` 등)와 `START` 문구 | 이 텍스처들이 `USRDIR/0000` 안에 없습니다. 다른 아카이브 파일을 조사해야 합니다 |
| 신문 기사 2장, 인물 이름표 20여 장, 수첩 1장 | 세로쓰기·손글씨 등 개별 작업 필요 |

대사 품질(마침표 누락, 띄어쓰기 소실, 초벌 번역의 어색한 표현)도 계속 손보는 중입니다.
