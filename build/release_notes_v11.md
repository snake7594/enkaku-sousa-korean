## 적용 방법

원본 ISO는 **직접 덤프한 것**을 사용하십시오. 이 릴리즈는 게임 데이터를 포함하지 않습니다.

### 1. 원본 확인

```
certutil -hashfile "Enkaku Sousa Shinjitsu eno 23nichikan.iso" MD5
```

```
크기   739,835,904 바이트
MD5    9f9bb5eec3d2c37f184955b591923e1c
```

### 2. 패치

```
xdelta -d -s "Enkaku Sousa Shinjitsu eno 23nichikan.iso" Enkaku_Korean_v1.1.xdelta Enkaku_Korean.iso
```

xdeltaUI를 쓰는 경우 **Apply Patch** 탭에서 Patch에 `.xdelta`, Source에 원본 ISO를 지정하십시오.

### 3. 결과 확인

```
크기   739,835,904 바이트 (원본과 동일)
MD5    260ea83b87da858fa7c0e822f9d41b25
```

v1.0에서 갱신하는 경우에도 **원본 ISO에 적용**하십시오. v1.0 결과물에 덧씌우면 안 됩니다.

## v1.1에서 고친 것

### 설정 화면

v1.0에서 항목명이 사라지고 세로 줄무늬만 남던 문제를 고쳤습니다.

원인은 화면 구조를 반대로 파악한 것이었습니다. 회색 항목명은 배경 텍스처에 있고 그 위에 노란색 텍스처가 덧그려지는데, 배경에 없다고 판단해 빈 자리에 글자를 그려 넣어 잔해를 만들었습니다.

- 제목·설명문·항목명 8개 전부 한글
- 색은 원본 픽셀에서 추출해 원래 톤 유지
- **회색 배경 문구와 노란색 선택 문구가 같은 문구·같은 위치**
- 가독성 지적에 따라 볼드체를 정체로 바꾸고 크기 축소

### 타이틀 로고

```
遠隔捜査        →  원격수사      (원격 흰색 · 수사 빨강, 원본 색 그대로)
真実への23日間   →  진실을 향한 23일간
```

### 사전 · 해설 버튼

`辞典` / `解説` → `사전` / `해설` (선택 전·후 두 벌)

## 아직 남은 것

| 항목 | 사유 |
|---|---|
| 하단 버튼 (`選択`·`戻る`·`決定`) | 여러 문자열이 한 텍스처에 조각으로 붙어 있고 조각 경계가 코드에 있어, 잘못 고치면 HUD 전체가 깨집니다 |
| 타이틀 메뉴 (`最初から`·`続きから`·`データインストール`·`設定`)와 설명문 | 이 텍스처들은 `USRDIR/0000`에 없습니다. 다른 아카이브 파일에 있는 것으로 보여 별도 조사가 필요합니다 |
| 신문 기사 2장, 인물 이름표 20여 장, 수첩 1장 | 세로쓰기·손글씨 등 개별 작업 필요 |

대사 품질(마침표 누락, 띄어쓰기 소실, 초벌 번역의 어색한 표현)도 계속 손보는 중입니다.
